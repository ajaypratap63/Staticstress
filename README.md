# Staticstress
The aim of this project is to understand how the type of contact between two mating parts affects the stress, deformation and overall safety of an assembly, using the Static Stress Analysis tool in Autodesk Fusion 360.
A simple bracket-and-pin type assembly (two components joined at a curved joint) was taken as the test model.
The same force and the same fixed support were applied in every case. Only the contact type between the two bodies was changed. This way, the effect of contact type alone could be studied, keeping everything else constant - this is called a controlled comparative study.
In short, the project answers the question: "If two parts of a machine are joined in different ways (bonded, sliding, rough, etc.), how differently will the assembly behave under the same load?"
